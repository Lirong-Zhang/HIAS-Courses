一、改了图标或名称后：怎么“重装”（重点看这段）
----------------------------------------

图标和名称不像课表内容那样刷一下就更新。手机系统会把图标缓存
得很深，所以“换图标 / 换名称”必须重装一次才生效。

结论：只换图标 / 换名称 —— 需要卸载重装；
      只改课表内容 —— 不用重装，刷新即可（见第四节）。

【安卓 / 小米】
  1. 长按桌面上的图标 → 选择“卸载”（不是“移除”）。
     - 若只有“移除”：说明它只是快捷方式，直接移除即可。
  2. 打开 Chrome，访问：
     https://lirong-zhang.github.io/HIAS-Courses/
  3. 首次可能需要先在 Chrome 里“下拉刷新”一次，
     让浏览器读到新的 manifest 和图标。
  4. 点地址栏右侧/右上角菜单里的：
     “安装应用” 或 “添加到主屏幕”。
     - 地址栏最右边有个像“小电脑/小屏幕”的小图标，点它最直接。
     - 菜单里这一项不同版本叫法不同：“安装应用”“添加到主屏幕”
       出现其中一个就点。
     - 【重要】如果这两个都没有，通常是因为“已经装过了”：
       Chrome 认为不必再装，就把入口收起来了。请先确认第 1 步
       真的卸载掉了，再重新打开网页。
     - 本课表页面顶部还会自带一个金色按钮
       “安装「HIAS课表」到桌面”，出现就直接点它，效果一样。
     - 两个入口都没有时：在 Chrome 里清除本站的网站数据
       （设置 → 应用 → Chrome → 存储 → 清除缓存），再重新打开。
  5. 回到桌面，图标和名称就是新的“HIAS课表”了。

  注意：
  - 卸载再安装不会丢任何数据，课表内容都在网页里。
  - 如果装完还是旧图标，说明系统缓存没清干净：
    先“清除 Chrome 的网站数据”（设置 → 应用 → Chrome →
    存储 → 清除缓存），再重新安装一次。
  - 名称一般能自动更新，图标最顽固，所以图标对了基本就成功了。

【iPhone / iPad】
  1. 长按桌面图标 → “移除 App” → “从主屏幕移除”。
  2. 用 Safari 打开上面的网址。
  3. 点底部分享按钮 → “添加到主屏幕” → “添加”。

【电脑（Chrome / Edge）】
  地址栏右侧出现的“安装”图标点一下即可；
  或 菜单 → “安装 HIAS课表”。
  要重装：先在同位置点“卸载”，再重新“安装”。


----------------------------------------
二、第一次安装（还没装过的话）
----------------------------------------

前提：PWA 不能靠手机本地打开 index.html 安装，
      必须放在 HTTPS 网站上。本课表已经放在 GitHub Pages 上，
      所以直接用下面的网址即可，不需要自己建仓库。

1. 手机用 Chrome（安卓）或 Safari（苹果）打开：
   https://lirong-zhang.github.io/HIAS-Courses/

2. 页面出现“安装 HIAS课表 / 添加到主屏幕”提示就直接点；
   没有提示就点右上角菜单，找“安装应用 / 添加到主屏幕”。

3. 确认后桌面出现“HIAS课表”图标，点它就能当独立 App 用：
   - 没有浏览器地址栏
   - 自动显示今天日期、实时时钟、当前第几教学周
   - 自动算出“正在上的课”和“下一门课”
   - 顶部天气（联网时更新，断网不影响课表）
   - 点任意课程格子 → 弹出该课大纲与上课地点

----------------------------------------

四、改了课表内容后：怎么更新（不用重装）
----------------------------------------

课表数据全部在 index.html 底部的 <script> 里，只有两个地方：

  1) cs 数组 —— 每门课的时间、星期、节次、周次、地点
  2) DETAILS 对象 —— 每门课的大纲，用 id 和 cs 对应

改完以后：
  a. 在 GitHub 仓库里上传覆盖 index.html；
  b. 打开 sw.js，把第一行的版本号加一，例如：
        const CACHE_NAME = "my-schedule-v8";
     改成
        const CACHE_NAME = "my-schedule-v9";
     这一行非常关键：不加版本号，手机上的旧 App 会一直读旧缓存。
  c. Commit changes。

等待几十秒到几分钟 GitHub Pages 自动部署；
手机上把 App 彻底关掉再打开，就会取到新内容。
（只改课表内容时，不需要卸载重装。）


----------------------------------------
五、显示的还是旧版怎么办
----------------------------------------

按顺序试：

1. 确认 sw.js 的 CACHE_NAME 版本号已经加一，并已 Commit。
2. 手机上把这个 App 从后台彻底划掉，再重新打开。
3. 用 Chrome 打开网址，下拉刷新一次，再回桌面 App。
4. 仍不行 → 按第一节“卸载重装”走一遍。

原因是 PWA 有离线缓存，会优先用本地旧文件，属于正常现象。


----------------------------------------
六、小米手机特别注意
----------------------------------------

- 优先用 Chrome；其次 Microsoft Edge。
- 小米自带浏览器对 PWA 的“安装”表现因版本而异，可能只给快捷方式。
- 若系统弹出“允许添加桌面快捷方式 / 创建桌面图标”，选择允许。
- 安装成功却桌面没图标：检查
  设置 → 应用设置 → 权限管理 → 桌面相关权限。


----------------------------------------
七、这版的定位与限制
----------------------------------------

优 点：不需要服务器、不需要账号、免费、很稳定，
       断网也能打开，非常适合个人课表。

限 制：不会自动从学校教务系统同步。
       换课需手动改 index.html 里的数据，然后重新 Commit。
